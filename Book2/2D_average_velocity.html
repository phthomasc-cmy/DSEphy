Formulas:
• Magnitude: |Δr| = √(Δx² + Δy²)
• Avg Velocity: |v_avg| = |Δr| / t
• Angle from North: θ = tan⁻¹(|Δx| / Δy)
• Bearing: N θ° E if Δx ≥ 0, or N θ° W if Δx < 0.
